# 电机模型（`mps-formula/src/motors.rs`）

现实中的电机不是一个东西，是一族机器。这个模块把常见电机家族的**稳态
转矩–转速特性**收进公式层，让调用方能回答「这台电机在这个转速下出多大力、
吃多少电、会不会烧」。

索引见 [README.md](README.md)。

## 为什么需要它

在此之前，仓库里的「motor」指两样东西，都不是电机：

| 已有的 | 实际是什么 | 缺什么 |
| --- | --- | --- |
| `set_spring` / `world_joint_set_motor` | **控制器**（位置/速度伺服） | 不知道自己驱动的是什么机器 |
| `rotor/`（叶素+动量理论） | **旋翼空气动力学** | 是螺旋桨，不是电磁机械 |

两者都回答不了「多少转矩、多少电流、多少温升」。那是**机器**的属性，不是
关节的属性，所以它属于公式层。

## 覆盖的家族

| 家族 | 转矩–转速 | 调速方式 | 典型用途 |
| --- | --- | --- | --- |
| 有刷直流（他励/永磁） | 从堵转线性下垂 | 电压 | 绞盘、廉价驱动 |
| 直流串励 | 转矩随电流上升，无有限堵转 | 电压 | 起动机、历史牵引 |
| 无刷直流 / 永磁同步 | 线性下垂 + 齿槽纹波 | 逆变器（FOC/六步） | 无人机、机器人、电动车 |
| 步进 | 转矩随转速下降，离散步 | 脉冲 | 3D 打印、CNC |
| 异步（鼠笼） | 到临界转差近乎平坦，然后崩溃 | V/f 或矢量 | 工业泵、传送带 |
| 伺服（直流或交流） | 到额定转速恒转矩，之后恒功率 | 闭环 | 机床 |
| 直线电机 | 同其旋转孪生，力替代转矩 | 逆变器 | 龙门、磁浮 |
| 压电 / 超声 | 准静态力，共振驱动 | 共振 | 精密平台 |
| 形状记忆合金 | 相变出力，有滞回 | 焦耳加热 | 软体机器人、锁扣 |

## 每个家族的物理要点

### 有刷直流：一条直线

```
V = I·R + k_e·ω      （电枢回路）
τ = k_t·I            （转矩）
```

消去 `I` 得到转矩–转速直线：

```
τ(ω) = k_t·(V − k_e·ω)/R
```

从**堵转转矩** `k_t·V/R` 到**空载转速**。这条线就是直流电机"一加载就掉速"
的全部原因。

模块里区分两个空载转速，这个区分很重要：

- `ideal_no_load_speed()` = `V/k_e` — 电磁转矩为零的点（电路代数给的）
- `no_load_speed()` = 扣除摩擦后的真实点，`V/k_e` 稍小

混用两者会让转矩曲线在"零转矩点"返回非零值，也就是一条声称过零却不
过零的线。这个 bug 在实现时真的出现过，被
`dc_passes_through_zero_at_no_load_speed` 抓住。

### 直流串励：双曲线，而且会飞车

串励的励磁电流就是电枢电流，磁通正比于电流，所以 `τ ∝ I²`：

```
τ(ω) = k / (ω + ω_0)
```

两个后果对物理引擎很关键：

1. **堵转转矩在模型里无界** —— 越慢越有力。真实起动机会这样烧掉自己，
   所以没有有限的堵转数可以 clamp，调用方必须自己限流。
2. **空载会飞车** —— 没有转矩需求时 `ω → ∞`。**绝不要**把它接到自由关节上
   而不加速度上限。`speed_limit_for_power()` 就是给这个用的。

### 无刷 / 永磁同步：同一台机器，多了纹波

电学上和有刷直流一样（同一条下垂线）。逆变器带来的是随转速缩小的**电压上限**
（弱磁），磁路带来的是**齿槽转矩**：

```
τ(ω, θ) = τ_droop(ω) + τ_ripple·sin(n·θ + φ)
```

`n` 是每转的齿槽周期数。纹波是位置伺服感觉到的"顿挫"，也是低分辨率编码器
无法与噪声区分的东西。

### 步进：转矩随转速掉，这是它的定义性缺陷

步进只在转子滞后于指令磁场时出力，而滞后被限制在一个整步内，所以可用转矩
随转速下降：

```
τ_pullout(ω) = τ_hold / √(1 + (ω/ω_corner)²)
```

低于拐点转速时基本就是保持转矩；高于则按 `1/ω` 掉，功率趋于平台。这就是
步进必须斜坡加速、否则丢步的原因。`max_start_rate()` 给出从静止能起步的
最高步频。

### 异步：靠转差，同步转速处无力

转矩取决于**转差** `s = (ω_sync − ω)/ω_sync`，用 Kloss 形式：

```
τ(s) = 2·τ_max / (s/s_max + s_max/s)
```

它在 `s_max` 处峰值（临界/崩溃转矩），之后崩溃。临界转差以下是稳定自调节
区——这是异步电机统治工业的原因——但它**在同步转速处无法出力**，也不能在
重载下全压启动。

### 伺服：包络，不是力律

```
τ(ω) = τ_rated               ω ≤ ω_rated   （恒转矩）
τ(ω) = τ_rated·ω_rated/ω     ω_rated < ω ≤ ω_max  （恒功率）
τ(ω) = 0                     ω > ω_max
```

注意这是**包络**：伺服被要求小转矩时就给小转矩。所以
`available_torque(omega, demand)` 要带上需求，做饱和。

### 压电：力–位移直线，功在阻塞力一半处

堆叠压电伸长 `ΔL = d₃₃·V·n`，阻塞力 `F_block = k·ΔL`；超声电机则把行波
转成运动。两者的力–位移关系都是从阻塞力到自由位移的一条直线。

`work_per_stroke` 在**阻塞力一半**处取最大——经典的阻抗匹配结果，也是压电
驱动负载时要跑在远低于阻塞力处的原因。

### 形状记忆合金：热执行器，滞回且单向

加热到奥氏体终了温度以上会恢复固定应变并产生回复应力；冷却后可以再次被
拉伸。带宽由加热/冷却速度决定（所以 SMA 丝很细），行程受可恢复应变限制
（几个百分点），因此是**高力/低行程**器件。

`actuation_fraction` 用中心在 `austenite_finish`、宽度 10 K 的 logistic，
捕捉"冷则软、热则缩"，**不**声称建模了滞回环——需要滞回的调用方自己跟踪
升温/降温。

## 参数值不是数据表

模块里每个具体数值都是**示例**，物理上合理，但不是任何真实产品的规格。
代码里明确标注了这一点，也没有任何地方把它当默认值使用。

`docs/evidence/` 只记录测试钉住的**不变量**（单调性、`k_t = k_e` 的 SI 恒等、
能量平衡、极限行为），从不记录数值本身。请不要把这些数当权威引用。

## 测试

`crates/mps-test/src/rapier/motors.rs`，47 项。刻意断言不变量而不是数值：

- 转矩随转速单调下降（每个家族各一条）
- `speed_at_torque` 与 `torque_at_speed` 互为逆（含"超出堵转返回 None"）
- 效率落在 `(0, 1]`，且不会超过 1
- 异步在同步转速处返回 `None`（无转差即无转矩），而不是返回 0
- 步进 `1/ω` 尾段（两倍转速 → 约一半转矩）
- 齿槽纹波不超过其声明幅值；周期数通过数符号变化验证
- 压电/SMA 的功在阻塞力一半处取最大
- 热模型收敛到 `p_loss·r_th` 的稳态，断电后会降温
- 所有非有限输入返回 `None` 而不是 NaN
## 怎么接进求解器

公式层只算，不施力。要让某台电机真的驱动一个关节，宿主每步做三件事：

```text
ω = world_multibody_joint_get_velocity(world, hinge, axis)   // 权威转速
τ = motor.torque_at_speed(ω)                                 // 算包络
world_multibody_joint_set_max_force(world, hinge, axis, |τ|) // 限幅
```

第三步用 ADR-0013 加的力矩上限。它和 impulse joint 那边的
`world_joint_set_motor` 的 `max_force` 参数是同一个概念，所以同一套
电机模型两条关节路径都能用。

**读转速必须用 `get_velocity`，不能读刚体 `angvel`。** 求解器每步用广义
速度覆盖 `bodies.vels`，读刚体拿到的是被覆盖过的二手值。

串联机构（机械臂、`articulation_body`）必须走 multibody，所以这条路径上的
力矩上限和转速读数缺一不可。
