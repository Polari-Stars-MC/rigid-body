# 0028 — 米氏系数归一化修复

## 背景

[ADR-0025](0025-riccati-bessel-mie.md) 记录了 Riccati–Bessel 实现，同时留下一个
**未查清的问题**：

> `|a_1|` 在瑞利极限下比教科书值大约 1.52 倍。标度关系 `∝ x³` 完全正确，
> 但绝对系数偏大。已排除复数运算、`j_n`/`y_n` 闭式解、Wronskian、光学定理、
> `m = 1` 归零。问题局限在 `a_n`/`b_n` 的组装环节。

[ADR-0026](0026-exact-mie-integration.md) 用**分区策略**规避了它（`x  0.3` 走渐近式），
但偏差本身仍在。

这一条把它查清并修复。

## 根因

**`a_n` / `b_n` 的系数用错了：应该是 `m` 和 `1/m`，我写成了 `m²` 和 `1`。**

### 推导

Bohren–Huffman 的原始形式用 `j_n(mx)`：

```text
a_n = [m²·j_n(mx)·[x·j_n(x)]' − j_n(x)·[mx·j_n(mx)]']
      ─────────────────────────────────────────────────
      [m²·j_n(mx)·[x·h_n(x)]' − h_n(x)·[mx·j_n(mx)]']
```

换算到 Riccati–Bessel 时，关键是 **`j_n(mx) = psi_n(mx)/(mx)`** —— 有一个 `mx`
在分母上：

```text
m²·j_n(mx)·psi_n'(x) = m²·[psi_n(mx)/(mx)]·psi_n'(x) = m·psi_n(mx)·psi_n'(x)/x
```

分子分母共有的 `1/x` 约掉后，留下的系数是 **`m`**，不是 `m²`。

同理 `b_n` 的原始形式第一项是 `m·j_n(mx)`（无平方），换算后是 **`1/m`**。

### 为什么这个错误能骗过所有此前的检验

| 检验 | 为什么没抓到 |
| --- | --- |
| 光学定理 `Q_ext == Q_sca` | 分子分母同时错，约束自洽 |
| `m = 1` 归零 | `m = 1` 时 `m² = m`，两者相同 |
| `j_n`/`y_n` 闭式解 | 基础函数本来就对，错在组装 |
| Wronskian | 同上 |
| `Q_ext(m=1.33, x=10) ≈ 2.2` | **中等尺寸参数下两种系数差别很小**（见下） |

最后一条是关键：`x = 10` 时高阶项主导，`m` 与 `m²` 的差别被淹没在级数里，
所以对照文献只差 1.5%。**只有瑞利极限能暴露它。**

## 修复

```text
a_n 分子 = m   · psi_n(mx)·psi_n'(x) − psi_n(x)·psi_n'(mx)
a_n 分母 = m   · psi_n(mx)·xi_n'(x)  − xi_n(x)·psi_n'(mx)

b_n 分子 = (1/m)·psi_n(mx)·psi_n'(x) − psi_n(x)·psi_n'(mx)
b_n 分母 = (1/m)·psi_n(mx)·xi_n'(x)  − xi_n(x)·psi_n'(mx)
```

### 小 `x` 展开验证

用 `psi_1(z) ≈ z²/3`、`psi_1'(z) ≈ 2z/3`：

| 系数 | `a_1` 领头阶 | 与教科书 |
| --- | --- | --- |
| `m²`（修复前） | `-i(2/3)x³·(m³−1)/(m³+2)` | ❌ |
| `m`（修复后） | `-i(2/3)x³·(m²−1)/(m²+2)` | ✅ |

两式之比在 `m = 1.33` 时：

```text
(m³−1)/(m³+2) ÷ (m²−1)/(m²+2) = 0.31076 / 0.20401 = 1.5233
```

**精确等于观测到的 1.5233 倍偏差。** 这是根因的确证。

`b_n` 同理：用 `1/m` 时 `b_1` 的 `O(x³)` 项**精确抵消**，留下 `O(x⁵)`；用 `1`
（修复前的实现）不抵消，`b_1` 泄漏到 `O(x³)`。

## 三条新的回归测试

| 测试 | 断言 | 容差 |
| --- | --- | --- |
| `mie_a1_matches_the_rayleigh_limit_exactly` | `\|a_1\| = (2/3)k·x³` | `1e-6` |
| `mie_b1_is_two_orders_higher_than_a1` | `\|b_1\|/\|a_1\|  1e-3` | — |
| `rayleigh_qsca_matches_clausius_mossotti` | `Q_sca = (8/3)x⁴\|K\|²` | `1e-5` |

第三条是**最强的判据**：Clausius–Mossotti 因子 `(m²−1)/(m²+2)` 是电磁学基本结果，
不依赖任何米氏散射的具体形式。它同时钉住 `a_n` 和 `b_n` 的归一化。

## 分区策略的现状

[ADR-0026](0026-exact-mie-integration.md) 的 `best` 函数仍在 `x  0.3` 用渐近式。
**理由变了**：

| | 之前 | 现在 |
| --- | --- | --- |
| 理由 | 规避精确解的 1.52 倍错误 | **省算力**（渐近式是闭式，不跑级数） |
| 两个方法是否一致 | 否（差 1.52 倍） | **是（1e-6）** |

分区保留是合理的优化，不再是必需的正确性补丁。

## 一个方法论教训

ADR-0025 里我写了：

> 我在这上面做了 6 轮手工推导，每轮都发现前一轮有代数错误。继续手推的收益
> 已经很低，而可用的判据（Wronskian、光学定理、`m=1` 归零、`x=10` 对照）全部通过。

**"全部可靠的判据都通过"不等于"实现正确"。** 这一批证明了：

* 光学定理在**分子分母同时错**时仍然通过（自洽不等于正确）
* `m=1` 归零在**两系数在 `m=1` 重合**时仍然通过
* 文献对照在**高阶项主导**时区分力不足

**缺的是"绝对标度"判据。** 而 `(8/3)x⁴|K|²` 一直是可用的 —— 我在 ADR-0025 里
就测出过 `Q_sca` 偏大 2.5563 倍，但当时误判为"我的期望公式记错了"。

**教训：当实测与教科书常数差一个干净的倍数（1.52、2.5563）时，先怀疑实现，
再怀疑记忆。** 干净的倍数很少是巧合。

## 后果

- 米氏精确解在**全区间**（`x → 0` 到 `x ≥ 20`）现在都有独立判据支撑
- `tyndall` 的精度描述从"瑞利极限有 1.52 倍偏差"改为"两个区间都已验证"
- 三个 C ABI（ADR-0026/0027）的精度提升，签名不变

## 没做的事

1. **大 `|z|` 的连分式**：幂级数在 `|z| > 50` 时精度下降，未处理
2. **`Q_abs` 的独立验证**：只有结构性判据（`>= 0`、`= Q_ext − Q_sca`），
   没有文献对照值
