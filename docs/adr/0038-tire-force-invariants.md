# 0038 — 轮胎力的量纲与物理不变量

## 背景

[ADR-0037](0037-historical-defect-regressions.md) 把 ROADMAP 点名的三个历史缺陷里
补了两个回归防线，第三个**诚实记为未覆盖**：

> `tire_model_*` 是 scene 级接口（需要 `WorldHandle` + 整车 + 车轮），不是纯公式。
> 要做量纲检查，需要一个受力与载荷成线性的场景……**没有做，理由是成本与收益。**

这一条把它补上。用的是现有 `tire_model.rs` 的整车脚手架（`make_car`），
不需要新建基础设施。

## 四次失败的尝试（值得记录）

第一版写完直接跑，5 项全红。四次修正全部是**我的不变量假设错了**，不是实现错。

### 失败 1：`load_sensitivity = 0.0` 被拒

`tire_model_set_params` 的校验是 `load_sensitivity <= 0.0 → FALSE`。我原想用
`0.0` 让载荷因子退化为 `load^0 = 1`，直接拒绝。改用 `1.0`（线性载荷）——
载荷在两档 `μ` 之间**完全相同**，不影响 `μ` 的线性判据。

### 失败 2：单步断言全部落空

单步 `tire_model_update` 下，力与引擎力**几乎无关**（都是 9.43 N）。

原因：**滑移比是状态量**，由 `engine_force` 逐步积分而来。一步之内轮速还没养
起来，力由近乎为零的 `slip` 决定。所以「引擎力越大 → 力越大」在单步下不成立。

**这是把状态量当成纯函数来断言** —— 一个很容易犯、也最容易让测试变成空转的错误。

### 失败 3：逐档严格单调不成立

改成「引擎力 100 → 500 → 2000 → 10000，力必须单调不减」仍然失败：
`9.4420 → 9.4225`（降了 0.2%）。

即使多步，滑移仍在演化，小增量下的抖动会破坏严格单调。**这个断言本身不成立**，
不能用。

### 失败 4：制动测不到负力

「驱动 → 满刹车 → 应有反向力」得到 **0**。

查明白了，这**不是 bug**：本文件的 `make_car` 把整车悬在自由空间（无地板、无水平
力施加到车身），**车速恒为 0**。此时：

| 状态 | `slip` | 力 |
| --- | --- | --- |
| 原地空转 | `> 0` | 正力 |
| 满刹车（轮速归零） | `= 0` | **0** |

真正的「滑移制动」（车比轮快，`slip < 0`）需要车身真的在动，而轮胎力**要由调用方
施加到车身**（见模块文档）。测试脚手架不做这件事，所以到不了那个区。

## 最终验证的 4 条不变量

| 测试 | 判据 | 抓什么 |
| --- | --- | --- |
| **`tire_longitudinal_force_scales_linearly_with_peak_mu`** | `F(μ=1.4)/F(μ=0.7)` **精确 = 2**（`1e-9`） | `μ` 的幂次错（`μ²` 会得 4，漏乘得 1） |
| `tire_force_stays_below_the_coulomb_cap` | `\|Fx\|,\|Fy\| ≤ μ·Fz_max`（`Fz_max=6000 N`） | 忘记封顶 |
| **`tire_force_saturates_and_becomes_independent_of_engine_force`** | 引擎力 **×100** 后力几乎不变（`20%` 内） | 无摩擦上限（无上限时比值接近 100） |
| `tire_braking_returns_force_to_zero_without_going_positive` | 制动全程 `fx ≤ 0`，末态趋于 0 | 制动符号写反 |

### 为什么「引擎力 ×100 → 力不变」是最强的一条

轮胎的物理本质是：进入摩擦饱和区后，**纵向力由 `μ` 与法向载荷决定，与发动机
输出无关**。这是 Magic Formula 与一切真实轮胎的标志。

一个没有摩擦上限的实现会让力与引擎力成正比 —— 比值接近 100。
**实测比值在 1.0 附近（20% 内），说明封顶确实生效。**

### `μ` 线性精确到 `1e-9`

`F(1.4)/F(0.7)` 与 2 的偏差小于 `1e-9`。这是**逐位精确**的线性关系，
说明 `μ` 在公式里以一次幂出现、且没有混入 `μ²` 或 `sqrt(μ)` 之类。

这正是「量纲错误」在数值上的表现方式：不是崩溃，是**幂次不对**。

## 仍未覆盖：滑移制动区

`slip < 0`（车比轮快）的制动行为未测，因为测试脚手架不把轮胎力施加到车身。

要做需要：

1. 建一个带地板的场景（车真的在地上跑）
2. 每步 `tire_model_get_forces` → 用 `rigid_body_apply_impulse` 把力施加到车身
3. 跑若干步后刹车，验证 `slip` 变负、力为负且不超过库仑上限

这是一个**闭环驾驶循环**，比现有测试重一个量级。**诚实记录为未覆盖。**

## 一条方法论结论

这一条的 4 次失败全部来自**同一个错误**：

> **把状态量当成纯函数来断言。**

滑移比、轮速都是通过 `dt` 积分出来的状态。它们的瞬时值不满足"输入增大 →
输出增大"这种函数式断言。正确的做法是先跑多步到稳态，或者断言**界**而不是
**序**（如"不超过库仑上限"成立，"单调不减"不成立）。

这与 [ADR-0036](0036-analytic-reference.md) 的纯公式层形成对比：那里所有断言都是
无状态函数，所以 27 项一次通过。**有状态的系统难验证得多**，这也是为什么
ROADMAP 点名的三个缺陷全部落在多步耦合处。
