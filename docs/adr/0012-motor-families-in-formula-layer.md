# 0012 — 电机家族进公式层：从「一个伺服」到「一族机器」

## 背景

2026-11-15 修完步进电机的刹车问题（ADR-0011）后暴露了一个结构性空白：
仓库里的「motor」指两样东西，**都不是电机**。

| 已有的 | 实际是什么 | 缺什么 |
| --- | --- | --- |
| `set_spring` / `world_joint_set_motor` / `setMultibodyJointMotor` | 控制器（位置/速度伺服） | 不知道自己驱动的是什么机器 |
| `rotor/`（叶素 + 动量理论） | 旋翼空气动力学 | 是螺旋桨，不是电磁机械 |
| `transmission.rs` | 齿轮/凸轮/螺旋约束传动 | 是传动，不是原动机 |
| `control_theory.rs` | 通用控制论（能控性、Bode、Kalman） | 与具体机器无关 |

结果是一个很实际的缺口：能问「这个关节转到哪」，但问不了「这台电机在这个
转速下出多大力、吃多少电、会不会烧」。后者是**机器**的属性，不是关节的
属性。

## 决定

在 `mps-formula` 新增 `motors.rs`，覆盖现实里常见的电机家族。纯函数、
不进求解器、不加 C ABI —— 与 ADR-0010 给 Hertz/Mindlin 的定位一致：公式层
零 ABI 风险，先让调用方能算，再谈接线。

覆盖九个家族，每个都给出**稳态转矩–转速关系**加必要的损耗项：

1. **有刷直流（他励/永磁）** `τ(ω) = k_t·(V − k_e·ω)/R − τ_f`
2. **直流串励** `τ(ω) = k/(ω + ω_0)`，无有限堵转、空载飞车
3. **无刷直流 / 永磁同步** 线性下垂 + 齿槽纹波 + 弱磁电压地板
4. **步进** `τ(ω) = τ_hold/√(1 + (ω/ω_c)²)`，含起步步频
5. **异步（鼠笼）** Kloss 形式 `τ(s) = 2τ_max/(s/s_max + s_max/s)`
6. **伺服** 恒转矩 → 恒功率包络（包络不是力律，`available_torque` 带需求）
7. **直线电机** 同其旋转孪生，力替代转矩
8. **压电 / 超声** 力–位移直线，功在阻塞力一半处最大
9. **形状记忆合金** 热驱动、滞回、高力低行程

外加共用的电学/热学：`back_emf`、`copper_loss`、`electrical_time_constant`、
`thermal_step` / `thermal_steady_state` / `thermal_margin`。

## 两个刻意的建模选择

**1. 一阶集总热模型，并明说是第一阶。**
真实电机有绕组时间常数（秒）和机壳时间常数（分钟）。用一个节点假装同时
捕捉两者，比承认它是一阶更糟。需要第二个节点的调用方链两次调用即可。

**2. 参数值一律是示例，不是数据表。**
模块里每个具体数字都物理上合理，但不是任何真实产品的规格。代码里标注了，
也没有任何地方把它当默认值。`docs/evidence/` 只记录测试钉住的**不变量**，
从不记录数值本身——数值会随产品变，不变量不会。

## 后果

- 补上了「机器层」：现在可以算转矩、电流、铜损、温升、效率、起步步频、
  失速边界，而不只是「关节转到哪」。
- **不引入任何 C ABI**，所以 `rigid_body.h` / `metrics.rs` 的入口计数不变；
  只有测试数增加。
- 两个模型刻意**没有**覆盖的边界，都写进了文档和测试：
  - 异步电机在同步转速以上（发电态）返回 `None`，不返回 0；
  - 串励电机没有「零转矩转速」，`speed_at_torque(0)` 返回 `None` 而不是
    一个巨大的数——返回大数会掩盖飞车风险。
- 实现过程中被自己的测试抓到两个真 bug，都已修：
  1. `no_load_speed()` 原本返回 `V/k_e`（电磁转矩零点），但
     `torque_at_speed` 还减摩擦，于是「空载转速处转矩为零」不成立。
     拆成 `no_load_speed()`（扣摩擦）与 `ideal_no_load_speed()`（电路代数）。
  2. 齿槽周期计数测试把 `θ = 0` 数了两次（采样含两端点），修正为 `0..n`。
