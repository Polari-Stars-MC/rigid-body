# 0035 — 守恒律断言

## 背景

`docs/ROADMAP.md`「还开着」第 6 条列了三个历史缺陷，全部在「测试全绿」的状态下
存在过：

* **SPH 自贡献重复计算**（每个粒子把自己算进邻居）
* **轮胎力量纲错误**
* **光子动量必得 NaN**

它们的共同特征：**不是崩溃，不是 NaN，就是数值错了**。

[ADR-0034](0034-ffi-finiteness-sweep.md) 的有限性扫描抓不到这类 —— 输出是有限的
好数字，只是错的。这一条补上机械化的第二层：**守恒律**。

## 决定

新增 `crates/mps-test/src/rapier/conservation_laws.rs`，10 项测试，纯 C ABI 面。

### 七个物理场景

| 测试 | 断言 | 容差 |
| --- | --- | --- |
| `linear_momentum_is_conserved_without_forces` | 零重力无接触时 `Σm·v` 恒定 | `1e-10` |
| `angular_momentum_is_conserved_without_torques` | `Σm·(r×v)` 恒定 | `1e-9` |
| `free_fall_conserves_mechanical_energy` | `KE + m·g·y` 漂移 | `< 2%` |
| `elastic_collision_conserves_kinetic_energy` | `e=1` 正碰前后 KE | `< 5%` |
| `inelastic_collision_dissipates_energy` | `e=0` 时 KE 单调不增 | 严格 |
| `linear_damping_dissipates_energy_monotonically` | 阻尼下 KE 单调不增 | 严格 |
| `bodies_at_rest_stay_at_rest_in_zero_gravity` | 零重力静止体不漂移 | `1e-9` |

弹性/非弹性两条是**对照对**：同一条碰撞路径只改恢复系数，能量行为必须反向。
如果两条都「守恒」，说明恢复系数根本没生效。

### 三个 SPH 密度测试

`SPH 自贡献重复计算` 是 ROADMAP 点名的第一个缺陷，所以单独用**解析对照**钉住。

Poly6 核的解析式（与实现独立）：

```text
W(r, h) = 315/(64πh⁹) · (h² − r²)³     r < h
          0                             r >= h
```

归一化 `∫W dV = 1`（可验算：`4πh⁹·16/315 · 315/(64πh⁹) = 1`）。

取 `h = 1.2·d`，于是只有 `r = 0`（自身）与 `r = d`（6 个面心邻居）落在核内，
第二近邻在 `d√2 ≈ 1.414d > h` 之外。**每一项都可解析算出**：

```text
ρ = m·[ W(0,h) + 6·W(d,h) ]
```

| 测试 | 断言 |
| --- | --- |
| `sph_lattice_density_matches_the_analytic_sum` | 密度 = 解析值（`1e-12`） |
| `sph_density_is_linear_in_mass` | 质量翻倍 → 密度翻倍 |
| `sph_density_has_compact_support` | 核半径外粒子零贡献 |

**自身多算一次 → 相对偏差 `W(0)/(W(0)+6W(d)) ≈ 85%`**，绝对抓得到。

线性性与紧支撑两条抓的是另一类缺陷：质量被平方、漏乘质量、忘了判 `r >= h`。
它们能通过单点绝对值对照，但过不了这两个结构性质。

## 实测：引擎是对的

**这一批没有找到 bug。** 用临时探针打印实际漂移量确认断言不是空转：

| 场景 | 实测值 |
| --- | --- |
| 动量 | `\|p0\| = 9.12`，三轴漂移**精确 0** |
| 自由落体机械能 | `513.650 → 513.440`，相对漂移 `4.09e-4`（0.04%） |
| 弹性碰撞 | `8.377580 → 8.377580`，相对差 `2.1e-16`（机器精度） |
| 弹性碰撞末速 | `v_A.x = −4.0`（等质量完全交换速度，教科书正确） |
| 非弹性碰撞 | `8.3776 → 0.000000`（等质量正碰后全停，教科书正确） |

四条都符合解析预期。**Rapier 后端在这些场景是正确的** —— 这本身是有价值的信息，
因为以前没人验证过。

### 探针结论：断言不空转

如果只跑测试就宣布「全绿」，无法区分「引擎对」和「断言写松了」。探针的作用是
证明这些数字**真的在动**：动量非零（`|p0| = 9.12`）、能量非零（`e0 = 513.65`）、
角动量非零（测试里显式断言 `> 1.0`）。

## 与 ADR-0034 的分工

| | ADR-0034 有限性 | ADR-0035 守恒律 |
| --- | --- | --- |
| 覆盖 | 86 个零引用入口 | 7 个物理场景 + SPH 密度 |
| 抓什么 | 返回 `TRUE` 却给 `NaN`/`inf` | 数值有限但**算错** |
| 判据 | `输出必须有限` | `总量守恒` / `解析值` |
| 成本 | 表驱动，一次跑完 | 每个场景手写 |

**两个都必要，不能互相替代。** 有限性抓 `exp(x)−1` 相消与 `powf` 溢出；
守恒律抓量纲错误与漏乘系数。

## 一个设计细节：为什么显式关掉阻尼与休眠

`spawn` 里显式调用：

```rust
rigid_body_builder_set_can_sleep(b, Bool::FALSE);
rigid_body_builder_set_linear_damping(b, 0.0);
```

不关休眠，物体在无外力时会被冻结，「守恒」变成平凡的真。
不清零阻尼，能量会被静默抽走，守恒断言会误报为「引擎错」。

**测试的基础设施本身必须先排除干扰源**，否则测的是干扰不是引擎。

## 没做的事

1. **转动动能**：所有测试用零 `angvel`，所以只断言轨道角动量与平动动能。
   自转能量 `½Iω²` 未纳入 —— 需要读惯性张量，当前 ABI 没有直接暴露
2. **接触下的能量**：静止堆叠、滚动摩擦的能量账未测
3. **SPH 动量守恒**：只测了密度估计，没测孤立流体的总动量
4. **约束（关节）的能量**：`joints` 模块的约束冲量能量账未测
