# 0025 — Riccati–Bessel 与米氏精确解

## 背景

[ADR-0018](0018-tyndall-effect-data-layer.md) 的 `mie_scattering_efficiency` 用的是
**三段渐近近似**（瑞利极限 / van de Hulst 反常衍射 / 消光佯谬），误差 10~20%。

当时的理由是：**精确米氏解需要 Riccati-Bessel 函数的级数求和，而仓库里没有
贝塞尔函数实现（0 处），引入需要新增数值库依赖。**

这一条把这个缺口补上。

## 决定

新增 `mps_formula::bessel`，自己实现：

1. 最小复数类型（只需 `+ - * /`）
2. 球贝塞尔 `j_n` / `y_n`（Miller 向下递推）
3. Riccati–Bessel `psi_n` / `chi_n` / `xi_n`
4. 米氏系数 `a_n` / `b_n`
5. Wiscombe 截断阶数

### 为什么不引入 `num-complex`

`mps-formula` 目前**零外部依赖**（只有本地 proc-macro）。这是刻意的：公式层要能
在任何宿主里编译。

米氏散射需要的复数运算只有四种，不需要 `sqrt`/`exp`/`log`/三角函数。60 行足够。

## 已验证正确的部分（7 项）

这些都有测试，且判据**不依赖我记的文献值**：

| 检验 | 判据 | 结果 |
| --- | --- | --- |
| 复数四则运算 | `(a/b)*b == a`、`a*recip(a) == 1` | ✅ |
| `j_0`、`j_1` | 对照 `sin(x)/x`、`sin(x)/x²-cos(x)/x` | ✅ 1e-8 |
| `y_0`、`y_1` | 对照 `-cos(x)/x`、`-cos(x)/x²-sin(x)/x` | ✅ 1e-10 |
| `psi_0`、`chi_0` | `psi_0 = sin(x)`、`chi_0 = cos(x)` | ✅ 1e-10 |
| **Wronskian** | `psi_n·chi_n' - psi_n'·chi_n = -1` | ✅ 1e-8 |
| **光学定理** | 无吸收时 `Q_ext == Q_sca` | ✅ 1e-16 |
| **`m = 1` 归零** | 无折射率对比时 `a_n = b_n = 0` | ✅ 1e-12 |

**Wronskian 的符号是 `-1` 不是 `+1`** —— 因为 Bohren–Huffman 定义
`chi_n = -rho·y_n`，于是 `chi_0 = cos(x)`，直接验算 `n=0`：

```text
W = sin(x)·(-sin(x)) - cos(x)·cos(x) = -1
```

我最初断言 `+1`，跑出来是 `-1`。**那是测试错，不是实现错。**

## 尚未查清的部分（诚实记录）

**`|a_1|` 在瑞利极限下比教科书值大约 1.52 倍。**

教科书：`|a_1| ≈ (2/3)·[(m²-1)/(m²+2)]·x³`

实测：标度关系 `∝ x³` **完全正确**（`x` 增大 10 倍时 `|a_1|` 增大 1000 倍，
误差 < 1%），但绝对系数偏大。

已排除的可能：

* 复数四则运算 ✅
* `j_n` / `y_n` 的闭式解 ✅
* Wronskian ✅
* 光学定理 ✅
* `m = 1` 归零 ✅

所以问题局限在 **`a_n` / `b_n` 的组装环节**，或**我记的教科书公式漏了因子**。

同一批里 `Q_ext(m=1.33, x=10) = 2.168` 与文献 `2.2` 只差 1.5%，说明
**中等尺寸参数下实现是对的**。矛盾集中在 `x → 0` 的极限。

### 为什么不再深挖

我在这上面做了 6 轮手工推导，每轮都发现前一轮有代数错误。**继续手推的
收益已经很低**，而可用的判据（Wronskian、光学定理、`m=1` 归零、`x=10` 对照）
全部通过。

所以本批的**测试只断言可靠判据**：

* 标度关系（`∝ x³`）而不是绝对系数
* 光学定理
* `m=1` 归零
* 单调性
* `x=10` 的文献对照（5% 容差）

**没有断言瑞利极限的绝对系数**，并在测试文档里写明原因。

## 一个必须记住的教训

**`b_n` 的公式抄错了一次。** 我第一版把 `m²` 放在了 `b_n` 分子的第二项上：

```rust
// 错的
let num_b = psi_mx * dpsi_x - m2 * psi_x * dpsi_mx;
```

结果 `x=5` 时 `|b_3| = 1.56 > 1`，**违反能量守恒**。正确的 `b_n` 完全不乘 `m²`：

```rust
// 对的
let num_b = psi_mx * dpsi_x - psi_x * dpsi_mx;
```

`|b_n| <= 1` 这个上界是很强的检验，`mie_coefficients_stay_finite` 抓到了它。

## 数值稳定性说明

### `j_n` 用 Miller 向下递推

向上递推 `j_{n+1} = (2n+1)/x·j_n - j_{n-1}` 在 `n > x` 时误差放大。Miller 算法
先任意取 `j_N = 0`、`j_{N-1} = 1e-30` 向下递推，再用解析的 `j_0 = sin(x)/x`
归一化。起始阶取 `n + 20 + ⌊x⌋`。

### `y_n` 用向上递推

与 `j_n` 相反，`y_n` 向上递推是稳定的（`y_n` 随 `n` 增大而增大）。

### 复参数 `psi_n(z)` 用幂级数

复参数不能直接用实数 Miller。这里用幂级数：

```text
j_n(z) = z^n/(2n+1)!! · Σ (-z²/2)^k / [(2k)!!(2n+2k+1)!!]
```

截断到相邻项相对变化 `< 1e-30` 或 200 项。

**这是本模块最脆弱的部分**：大 `|z|` 时幂级数会抵消失精。米氏散射的常见参数
范围内（`x < 50`）够用；更大尺寸参数需要连分式。

### 幂级数的双阶乘容易写错

首项是 `z^n / (2n+1)!!`，其中 `(2n+1)!! = 1·3·5···(2n+1)` —— **共 `n+1` 个因子**。

我第一版写 `while k < n`（`n` 个因子）得到的是 `(2n-1)!!`，少乘一个 `(2n+1)`。
这会让 `a_1` 在瑞利极限下偏大 3 倍。修正后从 6.67e-7 降到 2.07e-7。

## 后果

- 米氏精确解的**数学基础**已就位（`a_n`/`b_n` 可计算，`x=10` 对照通过）
- **尚未接入 `tyndall`**：现有的三段渐近式在未完全验证前反而更可信
- 未导出任何 C ABI —— 数学库先内部验证，接口留到确认后再开

## 没做的事

1. **瑞利极限的 1.52 倍差异**：见上文的诚实记录
2. **接入 `mie_scattering_efficiency`**：需要先解决上一条
3. **连分式算法**：大 `|z|` 时需要，当前幂级数不够
4. **C ABI**：没有导出任何入口
